Portmaster : le pare-feu applicatif open source pour Windows et Linux

Résumé : Portmaster est un pare-feu applicatif open source multiplateforme (Windows/Linux) qui permet de contrôler finement le trafic réseau par application, bloquer les traceurs et chiffrer les requêtes DNS. Son approche modulaire et sa compatibilité avec les outils existants en font une alternative intéressante aux solutions propriétaires pour renforcer la sécurité des postes de travail et serveurs.

RefluXFS : cette faille dans XFS donne un accès root sur RHEL, CentOS et AlmaLinux

Résumé : CVE-2026-64600 (RefluXFS) est une vulnérabilité critique du système de fichiers XFS permettant à un utilisateur local d'obtenir des privilèges root sur les distributions RHEL, CentOS et AlmaLinux. La faille exploite une mauvaise gestion des métadonnées, nécessitant une mise à jour immédiate des noyaux concernés pour éviter des attaques par élévation de privilèges.

NVIDIA Forms 37-Member Open Secure AI Alliance and Open-Sources NOOA Framework

Résumé : NVIDIA et 36 autres acteurs majeurs (Microsoft, IBM, Red Hat, etc.) lancent l'Open Secure AI Alliance pour standardiser la sécurité des modèles d'IA open source. L'initiative inclut le framework NOOA (Neural Open Operations Assurance) pour auditer et sécuriser les pipelines IA, avec un focus sur la transparence et la résilience contre les attaques adversariales.

GitHub Adds 3-Day Dependabot Cooldown to Limit Poisoned Package Adoption

Résumé : GitHub introduit un délai de 3 jours dans Dependabot avant l'ouverture d'une PR pour les nouvelles versions de dépendances, réduisant ainsi le risque d'adoption de paquets malveillants. Cette mesure s'ajoute aux politiques de cooldown configurables dans dependabot.yml, offrant un meilleur contrôle sur les mises à jour automatiques dans les pipelines CI/CD.

Ubuntu To Provide Virtualization HWE Stack For Ubuntu 26.04 LTS

Résumé : Canonical étend son support HWE (Hardware Enablement) à la virtualisation pour Ubuntu 26.04 LTS, incluant un noyau mis à jour et des pilotes optimisés pour les hyperviseurs (KVM, QEMU). Open Secure AI Alliance : Nvidia veut fédérer le standard de sécurité de l’IA

Résumé : L'Open Secure AI Alliance (OSAA), initiée par NVIDIA, vise à créer un écosystème ouvert de sécurité pour l'IA en impliquant plus de 35 entreprises (Microsoft, Adobe, IBM, etc.). L'alliance se concentre sur le développement d'outils et de frameworks communs pour sécuriser les modèles IA, avec un accent sur la transparence et la prévention des attaques par empoisonnement ou extraction de données.

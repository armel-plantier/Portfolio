Panne mondiale de GitHub

Résumé : GitHub subit une panne mondiale le 17 août 2026, avec 20 % d'erreurs sur le web, l'API, GitHub Actions, Copilot et les pull requests. Les équipes de Microsoft investiguent activement. Une panne de cette ampleur impacte directement les workflows CI/CD et les équipes DevOps.

Linux 7.3 : améliorations majeures pour les systèmes de fichiers et le noyau

Résumé : Linux 7.3 introduit des optimisations pour EXT4, XFS (FALLOC_FL_WRITE_ZEROES) et IOmap, améliorant les performances des systèmes de fichiers. Le noyau ajoute aussi le support Rust pour PowerPC, des améliorations SMP pour réduire la latence, et un nouveau pilote watchdog pour Lenovo.

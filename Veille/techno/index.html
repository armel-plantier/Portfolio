Cisco corrige 12 vulnérabilités critiques dans SD-WAN et IOS XE

Résumé : Cisco a publié des correctifs pour 12 vulnérabilités critiques (dont 3 notées 9.9 CVSS) affectant ses solutions Catalyst SD-WAN et IOS XE. Ces failles, découvertes lors d'un audit interne, permettent des attaques par déni de service, exécution de code à distance et élévation de privilèges. Une mise à jour immédiate est recommandée pour les environnements exposés.

Nouvelle faille Zapscape dans KVM permettant l'évasion de conteneurs

Résumé : Une vulnérabilité critique (CVE-2026-6800) dans le noyau Linux permet à un attaquant avec des privilèges dans une VM L1 d'échapper à l'isolation KVM et d'exécuter du code sur l'hôte. Le risque est particulièrement élevé lorsque la virtualisation imbriquée est activée pour des invités non fiables. Un correctif est disponible dans les noyaux stables 6.6.148+.

Résumé : HashiCorp, Veeam et la Django Software Foundation ont corrigé 11 vulnérabilités, dont une faille de type cross-tenant (CVSS 10.0) dans Terraform MCP Server permettant une prise de contrôle à distance. Routeurs Zbtlink livrés avec un backdoor d'usine

Résumé : VulnCheck révèle un backdoor intégré dans 20 modèles de routeurs chinois Zbtlink, permettant l'ouverture de shells root non authentifiés. L'implant, présent dans 21 images firmware sur 2 ans, expose les réseaux domestiques et professionnels à des attaques persistantes. Une mise à jour immédiate est nécessaire.

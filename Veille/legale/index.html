Coca-Cola confirme une violation de données après une attaque par ransomware

Résumé : Coca-Cola a confirmé une violation de données suite à une attaque par ransomware ciblant sa filiale Fairlife. Le groupe Anubis revendique l'attaque et menace de publier les données volées. L'incident illustre les risques croissants de cyberattaques ciblant les infrastructures critiques des entreprises.

Nvidia et géants tech lancent une alliance pour la sécurité de l'IA

Résumé : Nvidia, en collaboration avec d'autres acteurs majeurs, a lancé une coalition dédiée à la sécurité des modèles et agents IA. L'objectif est de fournir des outils open source pour tester, auditer et protéger les systèmes d'IA contre les vulnérabilités et les attaques. Cette initiative répond à l'essor des menaces liées à l'IA générative.

Nouvelles politiques de GitHub et PyPI renforcent la sécurité de la chaîne d'approvisionnement

Résumé : GitHub et PyPI ont mis à jour leurs politiques pour améliorer la sécurité des dépendances logicielles. GitHub introduit un délai de trois jours avant l'ouverture des pull requests via Dependabot, tandis que PyPI bloque désormais les téléchargements de fichiers pour les versions de plus de 14 jours. Ces mesures visent à réduire les risques de compromission des chaînes d'approvisionnement.

Vulnérabilité critique dans PTC Windchill exploitée dans une campagne de ransomware

Résumé : Une faille de désérialisation non sécurisée dans PTC Windchill, permettant l'exécution de code à distance sans authentification, est activement exploitée par des cybercriminels. Cette vulnérabilité a été intégrée dans une campagne de ransomware, soulignant l'urgence de corriger les systèmes exposés.

MedusaHVNC : un nouveau malware utilise des bureaux Windows cachés pour échapper à la détection

Résumé : Le malware MedusaHVNC, proposé en tant que service (MaaS), exploite des bureaux Windows invisibles pour maintenir un accès persistant et furtif aux systèmes compromis. Cette technique permet aux attaquants de contourner les mécanismes de détection traditionnels, posant un défi majeur pour les équipes de sécurité.

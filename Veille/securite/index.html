Lundi 11 Août 2026

Multiples vulnérabilités dans OpenSSH

Résumé : De multiples vulnérabilités critiques ont été découvertes dans OpenSSH (versions antérieures à 9.8p1), permettant à un attaquant distant non authentifié d'exécuter du code arbitraire ou de provoquer un déni de service (DoS). Ces failles, liées à des erreurs de gestion de mémoire et de parsing des entrées, affectent principalement les systèmes Linux et Unix. Un correctif est disponible via les mises à jour officielles.

Multiples vulnérabilités dans les produits SAP

Résumé : Plusieurs vulnérabilités critiques (dont CVE-2026-38789 et CVE-2026-38790) ont été identifiées dans les produits SAP, permettant une exécution de code à distance (RCE), une élévation de privilèges et une fuite de données sensibles. Les composants affectés incluent SAP NetWeaver, SAP Business One et SAP Fiori. Des correctifs sont disponibles via le SAP Security Patch Day d'août 2026.

Multiples vulnérabilités dans Microsoft Windows

Résumé : Microsoft a corrigé 14 vulnérabilités critiques dans Windows, dont CVE-2026-68820 (RCE via le service Print Spooler) et CVE-2026-68821 (élévation de privilèges dans le noyau). Ces failles, exploitées en conditions réelles, permettent une prise de contrôle totale du système. Les correctifs sont disponibles via Windows Update (Patch Tuesday).

Résumé : Cisco a confirmé l'exploitation active de CVE-2026-20349, une faille critique dans les appliances Cisco ASA et Firepower, permettant un déni de service (DoS) à distance via un paquet malveillant. Les versions affectées incluent ASA 9.16 et antérieures. Un correctif est disponible via Cisco PSIRT.

Max severity SAP Commerce Cloud flaw (CVE-2026-42345)

Résumé : Une faille RCE de criticité maximale (CVSS 10.0) dans SAP Commerce Cloud (anciennement Hybris) est activement exploitée par le groupe Cl0p. Exploitée en conditions réelles, cette faille affecte toutes les versions modernes de Windows. Le correctif est inclus dans les mises à jour de sécurité d'août 2026.

Akira ransomware disables EDR via Safe Mode

Résumé : Les affiliés du ransomware Akira contournent les solutions EDR en redémarrant les machines infectées en mode sans échec avec réseau, puis en désactivant les protections avant de voler des données. Bien que le chiffrement échoue dans certains cas, l'exfiltration de données reste un risque majeur. Aucune mitigation universelle n'est disponible.

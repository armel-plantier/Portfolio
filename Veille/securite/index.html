Multiples vulnérabilités critiques dans Roundcube

Résumé : De multiples vulnérabilités critiques ont été découvertes dans Roundcube, un client webmail open-source. Certaines permettent une exécution de code arbitraire à distance (CWE-94), une atteinte à la confidentialité des données et une falsification de requêtes côté serveur (SSRF). Ces failles affectent les versions non patchées et exposent les serveurs de messagerie à des attaques massives. Un correctif est disponible via la mise à jour vers la version 1.6.6.
